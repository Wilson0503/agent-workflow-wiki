AI Agent 怎麼做事？從 Loop 到 Graph

把「生成式 AI」第 7～10 週的課程內容整理成一個 LLM Wiki，再用一條有檢查點的 Graph 流程，從 Wiki 產生給初學者看的教學簡報。簡報每一頁都標出它引用了哪些 Wiki 條目。

  • 教學簡報15 頁。用 ← → 翻頁，「講義模式」可以一次展開全部頁面與講者備註。
  • LLM Wiki6 頁來源摘要、19 個概念條目、1 頁總覽。每一點都標出來自哪一份課程資料。
  • 流程與檢查紀錄Loop / Graph 設計圖、實際執行的每一次檢查與失敗、反思。

這個專案怎麼運作

原始課程資料（raw/，唯讀）
  → LLM Wiki（wiki/）→ 格式檢查 → 事實抽查（另一個 Agent）
  → 大綱 → 大綱檢查 → 【人類審大綱】
  → 逐頁內容 ⇄ 事實審查（另一個 Agent，最多 3 輪）
  → HTML → 結構檢查＋截圖驗證 → 發佈
