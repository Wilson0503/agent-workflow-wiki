# 工具使用（Tool Use）

> 讓 AI 依需求挑選並呼叫外部工具，例如計算機或搜尋。

## 重點
- 定義：AI 根據需求選擇並使用工具（s3）。
- 工具例子：計算機、搜尋功能、自己寫的 function（s3）。
- 對應範例 07B（飲料店）（s2）。
- 現代 Agent 能調用工具、讀寫本機檔案，這是它和對話型 AI 的差別之一（s4）。

## 例子
- 07B 飲料店範例（s2；細節不在本 wiki 的來源中）。
- 檔案分類器 Agent 調用系統工具建資料夾、搬檔案（s4）。
